# Sécurité

Ce laboratoire utilise uniquement des runbooks et scénarios fictifs. Ne publiez pas de documentation interne, d’identifiants, de noms d’hôtes ou de données de production dans un dépôt public.

- L’application ne possède aucun accès à Kubernetes, Kafka ou aux hôtes documentés.
- Les commandes sont affichées, jamais exécutées.
- Ollama doit rester accessible uniquement sur la machine locale.
- Le masquage automatique réduit les risques mais ne garantit pas l’anonymisation complète.
- Les réponses doivent être relues avant toute intervention.

Signalez une vulnérabilité en privé au propriétaire du dépôt plutôt que dans une issue publique.
